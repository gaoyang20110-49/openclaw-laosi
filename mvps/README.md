# MVP 项目索引

> 以 MVP 模式进行技术探索的实验田

## 什么是 MVP？

MVP (Minimum Viable Product) 最小可行产品 —— 用最小的成本快速验证想法。

## 如何添加新 MVP

1. 在 `mvps/` 下创建新目录：`mvp-XXX-名称`
2. 创建 `README.md` 描述项目
3. 按需创建 `src/`、`config/`、`docs/` 子目录

## 命名规范

- 格式：`mvp-序号-功能简称`
- 示例：`mvp-001-feishu-bot`、`mvp-002-weather-alert`
