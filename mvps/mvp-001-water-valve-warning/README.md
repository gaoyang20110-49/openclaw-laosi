## 背景

IDC 数据中心基础设施系统相关的技术/业务逻辑内容

---

## 核心功能

1. **数据采集/获取**
   - 支持人工表格导入（CSV/Excel）
   - 预留 API 对接接口（未来可扩展）

2. **阀门预警逻辑配置与管理**
   - 阀门开度监测，精确到 0.1%
   - 前后时间点数据对比
   - 自动识别和预警

3. **预警通知与展示**
   - 仪表盘展示
   - 预警列表
   - 预警详情（含定位信息）

|------|------|
| 监控阀门数量 | ~1000 个 |
| 采样频率 | 1 分钟/次 |
| 数据精度 | 0.1% |

## 技术栈

- **后端**: Node.js + Express
- **前端**: Vue.js 3 + ECharts
- **数据存储**: JSON 文件
- **内网穿透**: Tunnelmole

---

## 快速启动

```bash
# 安装依赖
npm install

# 启动服务
PORT=3001 node src/server.js

# 或后台运行
PORT=3001 nohup node src/server.js &

# 启动内网穿透（可选）
tunnelmole 3001
```
